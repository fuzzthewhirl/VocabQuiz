# Project Instructions

- These instructions are the primary project rules for this repo.
- At the start of each new session, always read this file: `PROJECT_INSTRUCTIONS.md`.
- At the start of each new session, also read `.github/copilot-instructions.md`.
- At the start of each new session, read all prior session logs matching `session-ses_*.md` from the current working directory.
- Always store a session log for each session (e.g., `session-ses_YYYY-MM-DD.md` in the repo root).
- If the session file exists, update the **Updated** date and append a new User/Assistant entry.
- If the session file does not exist, create it with a standard header (title, Created, Updated) and then add the entry.
- Do this automatically without asking the user.
- Never commit or push to version control unless explicitly requested.
